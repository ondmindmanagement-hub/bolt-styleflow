# BOLT StyleFlow

BOLT StyleFlow is a hackathon scaffold for governed beauty and e-commerce AI workflows.

Current prototype:
- shows a simple user-facing workflow,
- records explicit decisions,
- requires approval for consequential purchase actions,
- keeps the integration boundary clear.

The YouCam API call is not yet implemented in this public scaffold. The next step is to connect an approved YouCam API account and replace the placeholder analysis/recommendation stage with real runtime calls.

This repository does not contain proprietary BOLT core source.
